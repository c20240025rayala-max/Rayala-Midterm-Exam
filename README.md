# Angels Burger

**Live site:** https://github.com/c20240025rayala-max/Rayala-Midterm-Exam.git

## About
 This website is inspired by the angels burger brand, it showcases their burgers and promotional content.

## Design System

### Palette (60-30-10)

| Role | Share | Color | Used for |
|---|---|---|---|
| Dominant | 60% | #FFF9ED | Page background and main content areas |
| Secondary | 30% | #242424 | Cards, footer, navigation, and dark section |
| Accent | 10% | #D92332 | Buttons, links, highlights, and primary actions|

### Visual style

**Style chosen:** Modern minimalist with bold branding

**Why I chose it:** i choose it for clean layout and aesthetic interface

### Contrast check

Body text color vs. background color: #242424 on  #FFF9ED
Contrast ratio: 14.5 : 1 (needs to be at least 4.5 : 1)
Tool used:WebAIM Contrast Checker — https://webaim.org/resources/contrastchecker/
